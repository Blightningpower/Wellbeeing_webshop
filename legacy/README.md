# Historisch bronmateriaal

Deze map bevat de oorspronkelijke, ongebruikte PHP-implementatie, accountpagina's en afbeeldingen. De huidige webshop heeft deze bestanden niet nodig.

Ze zijn bewaard om oud werk en originele afbeeldingen niet kwijt te raken. Dit is **geen werkende backend**: er zijn ontbrekende stylesheets, verouderde verwijzingen en onvolledige authenticatie.

- Niet publiceren of activeren als onderdeel van de winkel.
- De ontwikkelserver sluit deze map uit.
- De oude databaseverbinding gebruikt nu `DB_HOST`, `DB_USER` en `DB_PASSWORD` in plaats van vaste inloggegevens.
- Zie [de bestandscontrole](../docs/file-audit.md) voor de beoordeling per bestand.
